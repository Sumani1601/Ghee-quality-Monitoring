IoT-Based Ghee Quality Monitoring System

A compact IoT-based system designed to monitor key environmental and quality-related parameters of ghee and classify its quality into three grades using sensor data.

Project Overview

The project aims to provide a simple and low-cost approach for monitoring ghee quality using an ESP32-based sensing system. Multiple sensors collect relevant parameters, the readings are processed by the microcontroller, and the system classifies the sample into Grade A, Grade B, or Grade C based on the observed parameter values.

Problem Statement

Traditional quality assessment can require manual inspection or laboratory-based testing. This project explores an automated, sensor-based method that can provide quick monitoring and a simple quality classification for ghee samples.

Objectives

Monitor

Collect sensor readings related to the sample and its surrounding conditions.

Process

Use the ESP32 to acquire and process sensor data in real time.

Classify

Map the measured parameters to three quality categories: A, B, and C.

Display

Present readings and the resulting grade through an LCD interface.

Technologies & Components

ESP32 DHT11 Moisture Sensor Gas Sensor 16×2 I2C LCD Bluetooth Serial Embedded C/C++

How It Works

1. Sample & sensing The ghee sample is evaluated using the connected sensors.
2. Data acquisition The ESP32 reads the sensor values through its input interfaces.
3. Parameter evaluation The collected values are compared with the project's defined quality criteria.
4. Quality classification The system assigns the sample to Grade A, B, or C according to the combined parameter readings.
5. Output The measured values and quality grade can be displayed on the LCD and communicated through Bluetooth Serial.
